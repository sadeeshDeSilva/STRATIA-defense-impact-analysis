🌍 STRATIA (Strategic Intelligent Assistant) – AI Powered Analysis and Forecasting of Military Spending and Its Sustainable Impacts

📌 Project Overview

STRATIA is an AI-driven economic forecasting and decision-support system designed to predict key macroeconomic indicators such as GDP growth, inflation, unemployment, and other socio-economic factors using machine learning and deep learning models.

The system integrates an NLP-powered AI-Assistant interface, allowing users to input natural language queries and receive predictions along with detailed explanations and policy recommendations.

STRATIA also incorporates Explainable AI principles by combining rule-based reasoning with optional LLM-enhanced insights, making predictions more interpretable and actionable.




🛠️ Features

📊 Forecast multiple indicators:

                 GDP Growth

                 Inflation

                 Unemployment

                 Population

                 Health & Education Expenditure

                 CO₂ Emissions

                 Asylum Seekers & Refugees


🤖 NLP-powered chatbot (using spaCy):
Understands natural language queries
Extracts country, year, and defense expenditure


🧠 Deep Learning Models:

    LSTM-based time series forecasting
                           
    Machine-Learning forecasting (XGBoost, Random-Forest)

Multi-country modeling
💡 Intelligent Recommendation Engine:
Policy suggestions based on predictions
Economic reasoning

🧠 LLM Integration:

Enhanced explanations using Groq (LLama3) API

📈 Scenario-Based Forecasting:

Analyze impact of defense expenditure on economic indicators

🏗️ Project Architecture

          User Query (Natural Language)
                  ↓
          NLP Parsing (spaCy)
                  ↓
          Entity Extraction (Country, Year, Defense %)
                  ↓
          LSTM Models (Prediction Engine)
                  ↓
          Explanation + Recommendation Engine
                  ↓
          LLM Enhancement (Optional)
                  ↓
          Final STRATIA Response
